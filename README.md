# Bettercap Network Discovery & MITM Practice

**Status: partial demonstration; successful interception NOT verified**

**Tools:** Kali Linux, Bettercap, network discovery/sniffing modules

## Objective

Practice understanding local network discovery, ARP spoofing configuration, and network observation in a controlled learning environment.

## Visible workflow

- Started Bettercap and inspected devices through its network discovery modules.
- Configured ARP spoofing parameters for a selected target.
- Enabled network sniffing/observation functionality.
- Observed discovery-related traffic and tool output.
